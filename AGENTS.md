# Règles de gestion Git
- **NE JAMAIS faire de `git push` automatiquement**.
- Il est strictement interdit d'exécuter la commande `git push` (ou de pousser du code vers un dépôt distant) de votre propre initiative, même si le problème a été résolu.
- Vous devez **TOUJOURS** demander explicitement à l'utilisateur s'il souhaite pousser les modifications, et attendre sa confirmation avant de le faire. S'il n'y a pas de demande claire et explicite de l'utilisateur disant "tu peux pousser le code", ne le faites pas.
